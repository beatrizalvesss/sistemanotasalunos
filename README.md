# Sistema de Notas de Alunos

Projeto simples desenvolvido com HTML, CSS e JavaScript.
Permite  calcular médias de notas de forma prática.

## Funcionalidades
- Inserção de notas
- Cálculo automático da média
- Interface simples e intuitiva

## Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript

## Objetivo do projeto
Este projeto foi criado com fins de estudo e prática de desenvolvimento web,
servindo como base para aprendizado e para compor portfólio.
